# Project

This is a SwiftUI iOS render pipeline for Raven, a Figma Design-to-App system.

## Stack

- iOS
- SwiftUI
- Xcode
- GitHub Actions macOS runners
- iOS Simulator rendering
- Screenshot artifact generation

## Main paths

- App/ contains the Xcode project
- Render/ contains rendering scripts
- .github/workflows/render-ios.yml contains CI
- Artifacts/screenshots contains generated screenshots
